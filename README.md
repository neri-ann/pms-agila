# Seller Moon Procurement Management System

Seller Moon Procurement Management System enables users to efficiently create, track, and manage procurement requests. It features real-time progress monitoring, automated approval workflows, and a centralized supplier database for easy access. 

## Installation

- Clone the repository to your local machine: https://github.com/neri-ann/pms-agila.git
- Open the project folder using VS Code
- Open the terminal and go to frontend folder using 'cd frontend' command
- Run 'npm install' to install node modules
- Run 'npm start'
- Now you can run the frontend
- Follow same steps to run the backend in a split terminal

## Technologies

- **Frontend**: React.js, Tailwind CSS
- **Backend**: Node.js, Express.js, MongoDB
